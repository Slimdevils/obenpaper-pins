# Fonts

The Obenpaper house pair (§01 of the project-context md), used to render pin tiles.

| File | Family | Licence |
|---|---|---|
| `DMSerifDisplay-Regular.ttf` | DM Serif Display (Colophon Foundry) | SIL Open Font License 1.1 |
| `Poppins-Regular.ttf`, `Poppins-Medium.ttf` | Poppins (Indian Type Foundry) | SIL Open Font License 1.1 |

Both are distributed under the SIL OFL 1.1 (https://openfontlicense.org), which
permits bundling and redistribution with software. DM Serif Display and
Poppins Regular are the same files the site uses (`obenpaper-site/assets/fonts`).
